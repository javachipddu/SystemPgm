실행중인 프로그램을 프로세스라고 한다. 각 프로세스는 유일한 프로세스 번호 PID를 가지고 부모 프로세스에 의해 생성된다는 특징이 있다.

프로세스의 종류로는 시스템 프로세스와 사용자 프로세스가 있다. 
시스템 프로세스는 
시스템 운영에 필요한 기능을 수행하는 프로세스이고, 
사용자 프로세스는 
사용자 명령 혹은 프로그램을 실행시키기 위해 생성된 프로세스이다.

데몬 프로세스는 사용자와 직접 상호작용 하지 않는다. 백그라운드에서 계속 실행되고 있다. 시스템, 응용 프로그램의 기능을 지원하는 프로세스이다.

프로세스 명령어로는 프로세스 목록 확인을 위한 명령어인 ps - , 특정 프로세스를 검색하는 역할을 하는 명령어인 pgrep - 가 있다. 

강제종료는 Ctrl+C (^C) 
실행정지는 Ctrl+Z (^Z)이다.

프로세스를 끝내는 명령어는 kill이다.
