fork()란?

fork()는 유닉스(Unix) 계열 운영체제에서 새로운 프로세스를 생성하는 시스템 호출(System Call) 이다.

쉽게 말하면, 현재 실행 중인 프로세스를 복제하여 자식 프로세스(Child Process)를 만드는 함수다.

예를 들어 프로그램 A가 실행 중일 때 fork()를 호출하면 부모 프로세스와 거의 동일한 내용을 가진 자식 프로세스가 생성된다.

fork()는 부모와 자식에게 서로 다른 값을 반환한다.

자식 프로세스: 0, 부모 프로세스: (양수), 생성 실패: -1

요약: fork()는 현재 실행 중인 프로세스를 복제하여 새로운 자식 프로세스를 생성하는 유닉스 계열 운영체제의 시스템 호출이다. 
부모와 자식은 서로 다른 PID를 가지며 독립적인 메모리 공간에서 실행된다.
