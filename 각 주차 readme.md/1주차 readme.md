# Unix / Linux
위 운영 체제들은 PC, 스마트폰, 서버 등 다양한 곳에서 사용된다.
소프트웨어 산업에서 핵심적인 운영체제 기반 기술로 사용된다.
대표적인 Unix/Linux 기반 운영체제는 Android, iOS, Linux 등이 있다.

Unix 시스템은 User -> Shell -> System Call -> Kernel -> Hardware의 구조로 이루어져 있다.
Shell은 사용자와 운영체제 사이의 인터페이스 역할을 수행한다. 그리고 사용자가 입력한 명령을 해석하고 실행한다.
Kernel은 운영체제의 핵심 구성 요소이다. 하드웨어 자원을 직접 관리한다.
System Call은 프로그램이 커널 기능을 사용할 수 있도록 제공되는 인터페이스이다.
