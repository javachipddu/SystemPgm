라우터는 두 개 이상의 서로 다른 네트워크를 연결하는 장치이다.

$ ip addr를 입력하면
사용중인 시스템의 IP 주소를 출력한다.

$ hostname를 입력하면 
사용중인 시스템의 호스트명을 출력한다.

$ nslookup (호스트명)를 입력하면 
지정된 호스트의 IP 주소를 알려준다.

FTP 서버(File Transfer Protocol Server)는 인터넷을 통해 파일을 주고받기 위해 구축된 전용 컴퓨터이다.

권고 잠금은 
이미 잠금된 파일 영역에 대해서도 잠금 규칙을 무시하고 읽거나 쓸 수 있다. 
잠금을 할 수 있지만 강제되지는 않는다. 

강제 잠금은
잠금된 파일 영역에 대해 잠금 규칙을 무시하고 읽거나 쓸 수 없다. 
커널이 잠금 규칙을 강제하므로 시스템의 부하가 증가한다. 

fcntl() 시스템 호출을 이용하여 지정된 영역에 대해 잠금 검사, 잠금 설정 혹은 잠금 해제를 할 수 있다.

lockf()함수를 이용하여 지정된 영역에 대해 잠금 검사, 잠금 설정 혹은 잠금 해제를 할 수 있다.
