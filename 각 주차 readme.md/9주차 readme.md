쉘 스크립트는 여러 명령어를 파일로 묶어 자동화하는 텍스트 파일이다.

echo 명령어는 터미널에 텍스트를 출력하며, -n 옵션은 메시지 출력 후 줄 바꿈을 하지 않는다.

read 명령어는 사용자로부터 입력을 받아 변수에 저장하며, -p 옵션으로 프롬프트를 띄울 수 있다.

변수에 대해 알아보자.

시스템 환경 변수로는 
현재 사용자 이름($USER), 
사용자의 고유 ID 번호($UID), 
사용자의 홈 디렉터리($HOME), 
명령어 검색 경로($PATH)가 있다. 

사용자 정의 변수로는 할당과 참조가 있는데 
할당은 days=10 처럼 = 기호 앞뒤에 공백 없이 할당한다. 
참조는 value2=$value1처럼 변수명 앞에 $를 붙여 값을 불러온다.
