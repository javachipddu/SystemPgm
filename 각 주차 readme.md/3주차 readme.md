리눅스는 모든 것을 파일로 취급하고 디렉터리, 장치도 파일처럼 처리한다.

파일은 파일 정보(메타데이터)와 실제 데이터 두 부분으로 구성된다.

기본 명령어들

+ date -> 날짜 
+ hostname -> 시스템 이름
+ uname -> OS 정보 
+ uname -a -> 상세 정보
+ who -> 로그인 사용자
+ whoami -> 현재 사용자
+ ls -> 디렉토리 목록
+ passwd -> 비밀번호 변경
+ clear -> 화면 초기화

명령어 도움말 개념

+ man -> 상세 설명
+ info -> 추가 설명
+ --help -> 간단 사용법
+ whatis -> 한 줄 설명

특수 디렉토리 개념

+ / -> 루트
+ . -> 현재 디렉토리
+ .. -> 부모 디렉토리
+ ~ -> 홈 디렉토리

디렉토리 명령어 개념

+ pwd -> 현재 위치 출력
+ cd -> 디렉터리 이동
+ cd ~ -> 홈
+ cd .. -> 부모
+ mkdir -> 디렉터리 생성
+ mkdir -p -> 중간 경로 생성
+ rmdir -> 디렉터리 삭제 (빈 것만 가능)

파일 속성은 이름, 타입, 크기, 소유자, 권한, 수정 시간으로 구성되어있다.

파일 관련 명령어 정리

+ cat -> 파일 출력 
+ more -> 페이지 출력 
+ head -> 앞부분 출력 
+ tail -> 뒷부분 출력 
+ wc -> 줄/단어/문자 수 출력
+ cp -> 복사
+ mv -> 이동/이름 변경
+ rm -> 삭제
+ rm -r -> 디렉터리 전체 삭제 (위험한 방식)
