리눅스는 모든 것을 파일로 취급하고 디렉터리, 장치도 파일처럼 처리한다.

파일은 파일 정보(메타데이터)와 실제 데이터 두 부분으로 구성된다.


기본 명령어들

+ date -> 날짜 
+ hostname -> 시스템 이름
+ uname -> OS 정보 
+ uname -a -> 상세 정보
+ who -> 로그인 사용자
+ whoami -> 현재 사용자
+ ls -> 디렉터리 목록
+ passwd -> 비밀번호 변경
+ clear -> 화면 초기화


명령어 도움말 개념

+ man → 상세 설명
+ info → 추가 설명
+ --help → 간단 사용법
+ whatis → 한 줄 설명
