시스템 호출(System Call)은 응용 프로그램이 커널의 기능을 사용하기 위한 인터페이스이다. 커널은 운영체제의 핵심이다. 

시스템 호출(System Call)은 함수처럼 호출되지만 실제로는 커널 모드에서 실행된다는 특징이 있다.

C 라이브러리 함수는 시스템 호출을 직접 사용하기 쉽게 감싸놓은 함수이다.

printf() → 내부적으로 write() 시스템 호출 사용
fopen() → 내부적으로 open() 시스템 호출 사용

파일 입출력 과정
C 언어에서 파일 입출력은 파일 열기 -> 파일 입출력 -> 파일 닫기 순서로 이루어진다.

+ 파일 열기: fopen()
+ 파일 입출력: fread, fwrite, fgetc, fputc 등
+ 파일 닫기: fclose()

FILE 구조체는 하나의 파일 스트림에 대한 정보를 담고 있다.

버퍼 포인터, 
버퍼 크기, 
파일 상태 정보, 
파일 디스크립터를 포함하고 있다.

표준 입출력 스트림은 프로그램 실행 시 자동으로 열리는 스트림이다.

표준 입력(키보드)의 stdin, 
표준 출력(화면)의 stdout, 
표준 오류 출력의 stderr 가 있다.
