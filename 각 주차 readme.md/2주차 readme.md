# Linux

Linux는 다중 사용자(Multi-user), 다중 작업(Multi-tasking) 운영체제이다.
모든 것은 파일로 관리된다.
시스템은 계층적인 디렉터리 구조를 가진다.

Linux의 주요 디렉토리 기호로는
.   : 현재 디렉토리, 
..  : 부모 디렉토리, 
~   : 사용자 홈 디렉토리, 
/   : 루트 디렉토리 
가 있다.

기본 명령어로는 현재 작업 디렉토리를 출력하는 pwd, 디렉토리 이동의 cd, 목록 출력의 ls, 상세정보를 확인하는 명령어 -l, 숨김 파일을 포함하는 -a, 모두 출력하는 -al, 명령어에 별칭을 설정하는 alias가 있다.
