# Linux

Linux는 다중 사용자(Multi-user), 다중 작업(Multi-tasking) 운영체제이다.
모든 것은 파일로 관리된다.
시스템은 계층적인 디렉터리 구조를 가진다.

Linux의 주요 디렉토리 기호로는
.   : 현재 디렉토리, 
..  : 부모 디렉토리, 
~   : 사용자 홈 디렉토리, 
/   : 루트 디렉토리 
가 있다.

기본 명령어로는 
현재 작업 디렉토리를 출력하는 pwd, 
디렉토리 이동의 cd, 
목록 출력의 ls, 
상세정보를 확인하는 명령어 -l, 
숨김 파일을 포함하는 -a, 
모두 출력하는 -al, 
명령어에 별칭을 설정하는 alias가 있다.

파일 확인 명령어로는 전체 출력 cat, 
페이지 단위로 출력하는 more, 
앞부분을 출력하는 head, 
뒷부분을 출력 tail, 
줄/단어/문자 수를 출력해주는 wc가 있다.

파일 조작 명령어로는 
복사의 cp, 
이동 및 이름 변경이 가능한 mv, 
삭제를 담당하는 rm이 있다.

도움말 확인 명령어
man 명령어
info 명령어
명령어 --help
특징
man : 기본 매뉴얼 (가장 많이 사용)
info : 더 상세한 설명
--help : 간단한 옵션 설명

입출력 재지정 (Redirection)
명령어 > 파일
명령어 >> 파일
명령어 < 파일
> : 출력 덮어쓰기
>> : 출력 추가
< : 입력 변경
